## Analyze
Example Portfolio 1: [Tyler Wisniewski](https://tylerwisniewski.github.io/cev/)

This portfolio contains a tab dedicated to all of the available projects with pictures included, making it very quick to pick out the project you want to read about in a couple clicks.  However, no detail is provided beyond the photo as there isn't any sort of description or header until you click on a project.  This makes it harder to find a specific project you want to open in the instance that the photo doesn't make it obvious enough, which disrupts the intuitive layout.  only a handful have an image that clearly represents what the final product was, and despite than its not enough info to determine what the project was.  For most of the projects available to look through, there is little to no details related to reproducing the project.  Each page acts more as a reflection of the their time spent during the project and some of the challenges faced rather than procedure, so a colleague would absolutely need to ask questions. A select few projects contain a link to the full lab report where a detailed procedure can be found, this is not representative of most projects on the portfolio.  The same can be said for the reasoning behind the decisions they made, as this is only included in the projects that have links to reports.
