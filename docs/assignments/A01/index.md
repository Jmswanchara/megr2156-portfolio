Example Portfolio 1: [Tyler Wisniewski](https://tylerwisniewski.github.io/cev/)

**Navigability**

This portfolio contains a centralized tab dedicated to all of the available projects with pictures included, making it very quick to pick out the project you want to read about in a couple clicks.  However, each of the projects rely on unspecified images that don't include a description, forcing the user to click through each.  The intuitive layout of the projects tab is disrupted because only a few images display what the project is.

For most of the projects available to look through, there is little to no details related to reproducing the project.  Each page acts more as a reflection of the their time spent during the project and some of the challenges faced rather than procedure, so a colleague would absolutely need to ask questions. A select few projects contain a link to the full lab report where a detailed procedure can be found, this is not representative of most projects on the portfolio.  Unfortunately, the presence of reasoning behind problem solving decisions isn't present for many of the projects either.  Similar to procedure, most of the reasoning is included in links to the lab reports for the project, which adds a lot to the time it takes find the information you are looking for.  Finally, the professional language in the portfolio is lacking.  Some of the pages contain pictures and jokes that do not add to the project and only hold value to the people included in the project such as an inside joke.  Even though this isn't reflective of all the whole portfolio, as a whole this isn't something I'd want to share with a potential employer because such things stand out.
